## Школьное умножение квадратично

Умножая «в столбик» два n-значных числа, мы умножаем **каждую цифру на каждую**:

```text title="5491 · 1234 в столбик"
      5491
    × 1234
    ------
     21964
    16473
   10982
+ 5491
----------
   6775894
```

Это **n² умножений** отдельных цифр (и около n² сложений), а результат имеет 2n или 2n − 1 цифр. Для чисел из миллиона цифр — 10¹² операций. Можно ли быстрее?

## Умножение многочленов

Число, записанное цифрами, — почти многочлен: 5491 = 1 + 9·10 + 4·10² + 5·10³ (x = 10). Поэтому лекция занимается **умножением многочленов** — это та же задача.

:::def
Для A(x) = Σᵢ₌₀ⁿ⁻¹ aᵢxⁱ и B(x) = Σᵢ₌₀ⁿ⁻¹ bᵢxⁱ произведение C(x) = A(x)·B(x) = Σᵢ₌₀²ⁿ⁻² cᵢxⁱ, где

**cᵢ = Σⱼ aⱼ · bᵢ₋ⱼ**, то есть c₀ = a₀b₀, c₁ = a₀b₁ + a₁b₀, c₂ = a₀b₂ + a₁b₁ + a₂b₀, …
:::

Вычисление прямо по формуле — снова **n²** умножений коэффициентов.

## Первая идея: обычное «разделяй и властвуй» — выигрыша нет

Пусть n = 2ᵏ (при необходимости дописываем нули). Делим каждый многочлен на **нижнюю** и **верхнюю** половину коэффициентов:

- A(x) = Aₗ(x) + x^(n/2)·Aₕ(x), B(x) = Bₗ(x) + x^(n/2)·Bₕ(x).

Пример: у W(x) = 7x⁷ + 6x⁶ + 5x⁵ + 4x⁴ + 3x³ + 2x² + x − 1 будет Wₕ(x) = 7x³ + 6x² + 5x + 4 и Wₗ(x) = 3x³ + 2x² + x − 1, а W(x) = Wₗ(x) + x⁴·Wₕ(x).

Тогда:

**A·B = AₗBₗ + x^(n/2)·(AₗBₕ + AₕBₗ) + xⁿ·AₕBₕ** — четыре умножения многочленов вдвое меньшего размера.

Число умножений: T(1) = 1, T(n) = 4T(n/2), то есть **T(n) = n²**. Ничего не выиграли — нужна идея похитрее.

## Алгоритм Карацубы — три умножения вместо четырёх

Начинаем так же, но считаем только **три** произведения:

- **L(x) := Aₗ(x)·Bₗ(x)**
- **H(x) := Aₕ(x)·Bₕ(x)**
- **S(x) := (Aₗ(x) + Aₕ(x))·(Bₗ(x) + Bₕ(x))**

Заметьте: S = AₗBₗ + AₗBₕ + AₕBₗ + AₕBₕ, поэтому **средняя часть** AₗBₕ + AₕBₗ = **S − L − H** — без лишнего умножения! Значит:

:::def
**A(x)·B(x) = L(x) + x^(n/2)·(S(x) − L(x) − H(x)) + xⁿ·H(x)**
:::

**Пример с лекции:** A(x) = 1 + 2x, B(x) = 3 + 4x (n = 2), то есть Aₗ = 1, Aₕ = 2, Bₗ = 3, Bₕ = 4.

| Величина | Значение |
|---|---|
| L = AₗBₗ | 1 · 3 = 3 |
| H = AₕBₕ | 2 · 4 = 8 |
| S = (Aₗ + Aₕ)(Bₗ + Bₕ) | 3 · 7 = 21 |
| M = S − L − H | 21 − 3 − 8 = 10 |

Результат: A·B = 3 + 10x + 8x² ✓ (проверка: (1 + 2x)(3 + 4x) = 3 + 4x + 6x + 8x²).

### Сложность

K(1) = 1, **K(n) = 3·K(n/2)** ⇒ для n = 2ᵏ: **K(n) = 3ᵏ = n^(log₂ 3) ≈ n^1,585**.

Успехом мы обязаны тому, что при переходе к n/2 уменьшили число умножений **с 4 до 3**. Сложений немного больше, но это лишь O(n) на уровень. Лекция говорит, что алгоритм Карацубы выгоден для чисел в **несколько сотен бит** (примерно от 320 бит).

:::analogy
Вместо четырёх дорогих визитов к четырём специалистам вы делаете три и «вычитанием» их результатов вычисляете, что сказал бы четвёртый. Экономия четверти на каждом уровне рекурсии в сумме даёт огромную разницу: при n = 1024 это 59 049 вместо 1 048 576 умножений.
:::

## Большой вызов: спуститься до двух умножений?

Чтобы опуститься ещё ниже, нужна **другая идея** — лекция обращается к **интерполяции**.

:::def
**Интерполяционное свойство:** существует **ровно один** многочлен степени n, график которого проходит через n + 1 заданных точек с различными абсциссами.
:::

Кроме того, для любого x: **C(x) = A(x)·B(x)**. Значит, зная значения A и B в 2n − 1 точках, значения C в этих точках получаем за **2n − 1 обычных умножений чисел**, а по ним — однозначно — сам многочлен C.

**Проблемы:**

1. вычисление значения многочлена степени n в одной точке требует O(n) умножений (**схема Горнера**), значит, в n точках — **O(n²)**,
2. восстановление коэффициентов по значениям — это **интерполяция**, формула Лагранжа: A(x) = Σᵢ yᵢ · Πⱼ≠ᵢ (x − xⱼ)/(xᵢ − xⱼ) — тоже O(n²).

Может, хранить многочлены сразу как **значения в точках**? Тогда умножение и сложение линейны… но мы теряем почти всё остальное (лёгкое вычисление значений в новых точках, производные, корни, наглядность) — «ушат холодной воды».

**Искра надежды:** то, что значение в одной точке стоит O(n), не значит, что в n точках обязательно O(n²). У нас **свобода выбора точек** — может, их можно подобрать так, чтобы вычисления в одних точках использовались в других?

## БПФ (FFT) — быстрое преобразование Фурье (Кули, Тьюки, 1965)

Кули и Тьюки показали, что лучшие точки — это **корни n-й степени из единицы** на комплексной плоскости: ω⁰, ω¹, …, ωⁿ⁻¹, где ω = e^(2πi/n).

:::def
Свойства (n = 2ᵏ, показатели по модулю n):
- (ωⁱ)ʲ = ωⁱ ʲ, ωⁱ · ωʲ = ωⁱ⁺ʲ,
- **(ωₙⁱ)² = ωₙ/₂ⁱ** — квадраты корней n-й степени из единицы — это корни степени n/2 (каждый встречается дважды),
- ω^(n/2) = −1, поэтому ω^(k + n/2) = −ωᵏ.
:::

:::analogy
Корни из единицы — это n точек, равномерно расставленных по окружности, как часы на циферблате. Возведение в квадрат «удваивает угол» — и из 8 точек вдруг остаются лишь 4 различные. Именно это позволяет делить задачу пополам.
:::

### Разбиение на чётную и нечётную части

Делим многочлен на слагаемые с **чётными** и **нечётными** степенями. Из нечётных выносим x за скобку:

A(x) = a₀ + a₁x + a₂x² + … + a₇x⁷
 = (a₀ + a₂x² + a₄x⁴ + a₆x⁶) + x·(a₁ + a₃x² + a₅x⁴ + a₇x⁶)
 = **Aₑ(x²) + x·Aₒ(x²)**,

где Aₑ и Aₒ — многочлены степени n/2 − 1 (от переменной y = x²).

Для n = 8:

| точка | формула |
|---|---|
| A(ω⁰) | Aₑ(ω₄⁰) + ω⁰·Aₒ(ω₄⁰) |
| A(ω¹) | Aₑ(ω₄¹) + ω¹·Aₒ(ω₄¹) |
| A(ω²) | Aₑ(ω₄²) + ω²·Aₒ(ω₄²) |
| A(ω³) | Aₑ(ω₄³) + ω³·Aₒ(ω₄³) |
| A(ω⁴) | Aₑ(ω₄⁰) + ω⁴·Aₒ(ω₄⁰) |
| A(ω⁵) | Aₑ(ω₄¹) + ω⁵·Aₒ(ω₄¹) |
| A(ω⁶) | Aₑ(ω₄²) + ω⁶·Aₒ(ω₄²) |
| A(ω⁷) | Aₑ(ω₄³) + ω⁷·Aₒ(ω₄³) |

Видно, что достаточно вычислить значения **двух многочленов степени n/2 − 1 в n/2 точках** (рекурсивно тем же способом) и выполнить **n умножений**:

- T(1) = 1, **T(n) = 2T(n/2) + n** ⇒ **T(n) = O(n log n)**.

### Умножение многочленов через БПФ

1. БПФ: значения A в n корнях из единицы — O(n log n),
2. БПФ: значения B — O(n log n),
3. перемножаем значения: sₖ = A(ωᵏ)·B(ωᵏ) — n умножений,
4. **интерполяция** — восстанавливаем коэффициенты C по значениям s₀, …, sₙ₋₁.

Пока это «половинчатый успех»: 2(n log n + n) умножений, но нет быстрой интерполяции.

### Ключевая идея: интерполяция — тоже БПФ

Пусть искомый многочлен R(x) = Σⱼ rⱼxʲ, а его значения R(ωⁱ) = sᵢ известны. Построим многочлен S(x) = Σⱼ sⱼxʲ **с известными значениями в роли коэффициентов** и вычислим его значение в точке ω⁻ᵗ (симметричной ωᵗ относительно вещественной оси). Выкладка с лекции даёт:

**S(ω⁻ᵗ) = n · rₜ**, то есть **rₜ = S(ω⁻ᵗ) / n**.

Значит, интерполяция в корнях из единицы — это:

1. составить S(x) из значений s₀, …, sₙ₋₁,
2. вычислить **БПФ** многочлена S (в точках ω⁻ᵗ),
3. поделить результаты на n.

Общая стоимость умножения многочленов: **3n log n + n умножений** — то есть **O(n log n)** вместо n²!

На практике БПФ считает в числах с плавающей точкой — результат нужно **округлять** (`Math.round`), а на очень больших данных могут мешать ошибки округления. Тогда используют версию по модулю простого числа (NTT).
:::

=== summary ===

## Умножение

- школьное: **n²** умножений цифр; многочлены: cᵢ = Σⱼ aⱼbᵢ₋ⱼ.
- разбиение A = Aₗ + x^(n/2)Aₕ; 4 произведения → T(n) = 4T(n/2) = **n²** (выигрыша нет).

## Карацуба

- L = AₗBₗ, H = AₕBₕ, S = (Aₗ + Aₕ)(Bₗ + Bₕ), середина = **S − L − H**.
- **A·B = L + x^(n/2)(S − L − H) + xⁿH**.
- K(n) = 3K(n/2) ⇒ **n^(log₂ 3) ≈ n^1,585**; выгоден примерно от 320 бит.
- (1 + 2x)(3 + 4x): L = 3, H = 8, S = 21, M = 10 → 3 + 10x + 8x².

## Интерполяция

- многочлен степени n ⇔ значения в n + 1 точках; C(x) = A(x)B(x) поточечно.
- Горнер O(n) на точку; Лагранж O(n²).

## БПФ (Кули–Тьюки 1965)

- точки: корни n-й степени из единицы; (ωₙⁱ)² = ωₙ/₂ⁱ; ω^(n/2) = −1.
- **A(x) = Aₑ(x²) + x·Aₒ(x²)**; T(n) = 2T(n/2) + n = **O(n log n)**.
- интерполяция: **rₜ = S(ω⁻ᵗ)/n** — тоже БПФ.
- умножение многочленов: 2× БПФ + n умножений + обратное БПФ ≈ 3n log n + n.

:::task level=1 source="own" title="Карацуба для двух двучленов"
Умножьте алгоритмом Карацубы многочлены **A(x) = 3 + 5x** и **B(x) = 2 + 7x**. Укажите L, H, S, M и результат. Проверьте прямым умножением.
::hint
Aₗ = 3, Aₕ = 5, Bₗ = 2, Bₕ = 7.
::solution
- L = 3 · 2 = **6**
- H = 5 · 7 = **35**
- S = (3 + 5)(2 + 7) = 8 · 9 = **72**
- M = S − L − H = 72 − 6 − 35 = **31**

A·B = **6 + 31x + 35x²**. Проверка: (3 + 5x)(2 + 7x) = 6 + 21x + 10x + 35x² ✓. Мы использовали 3 умножения вместо 4.
:::

:::task level=2 source="own" title="Карацуба на числах"
Вычислите **47 · 63** методом Карацубы, считая числа многочленами от x = 10 (47 = 7 + 4x, 63 = 3 + 6x).
::hint
Найдя коэффициенты c₀, c₁, c₂, подставьте x = 10 (переносы «посчитаются» сами).
::solution
- L = 7 · 3 = 21, H = 4 · 6 = 24, S = (7 + 4)(3 + 6) = 11 · 9 = 99, M = 99 − 21 − 24 = 54.
- Многочлен: 21 + 54x + 24x².
- При x = 10: 21 + 540 + 2400 = **2961** ✓ (47 · 63 = 2961).
:::

:::task level=1 source="own" title="Сколько умножений?"
Сколько умножений коэффициентов сделает алгоритм Карацубы для многочленов с **n = 8** и **n = 16** коэффициентами? А школьный метод? Во сколько раз меньше при n = 1024?
::hint
K(n) = 3K(n/2), K(1) = 1, значит K(2ᵏ) = 3ᵏ.
::solution
- n = 8 = 2³: K = 3³ = **27** (школьный метод — 64),
- n = 16 = 2⁴: K = 3⁴ = **81** (школьный — 256),
- n = 1024 = 2¹⁰: K = 3¹⁰ = **59 049** против 1 048 576 — примерно в **17,8 раза** меньше.
:::

:::task level=2 source="own" title="Значения в корнях из единицы"
Для **A(x) = 1 + 2x + 3x² + 4x³** вычислите значения в четырёх корнях 4-й степени из единицы: 1, i, −1, −i. Сделайте это методом БПФ: запишите A(x) = Aₑ(x²) + x·Aₒ(x²).
::hint
Aₑ(y) = 1 + 3y, Aₒ(y) = 2 + 4y. Для x = ±1 имеем y = x² = 1, для x = ±i — y = −1, поэтому хватит двух значений Aₑ и двух Aₒ.
::solution
- y = 1: Aₑ(1) = 4, Aₒ(1) = 6; y = −1: Aₑ(−1) = −2, Aₒ(−1) = −2.
- A(1) = 4 + 1·6 = **10**
- A(i) = −2 + i·(−2) = **−2 − 2i**
- A(−1) = 4 + (−1)·6 = **−2**
- A(−i) = −2 + (−i)·(−2) = **−2 + 2i**

Проверка, например, A(i) = 1 + 2i + 3i² + 4i³ = 1 + 2i − 3 − 4i = −2 − 2i ✓. Заметьте: пары (1, −1) и (i, −i) используют одни и те же значения Aₑ, Aₒ — в этом и экономия БПФ.
:::

:::task level=3 source="own" title="Почему именно корни из единицы?"
Объясните своими словами, почему БПФ требует, чтобы точки были корнями n-й степени из единицы (а n — степенью двойки). Что было бы, если выбрать точки 1, 2, …, n?
::hint
Что происходит с множеством точек после возведения их в квадрат?
::solution
Рекурсия A(x) = Aₑ(x²) + x·Aₒ(x²) требует вычислить Aₑ и Aₒ в точках **x²**. Для корней n-й степени из единицы множество квадратов содержит лишь **n/2** элементов и является множеством **корней степени n/2** — ровно та же задача вдвое меньшего размера (и так до n = 1, поэтому n = 2ᵏ). Отсюда T(n) = 2T(n/2) + n = O(n log n).

Для точек 1, 2, …, n квадраты 1, 4, 9, …, n² **все различны** — задача вовсе не уменьшается (по-прежнему n точек), экономии нет: стоимость остаётся O(n²).
:::
