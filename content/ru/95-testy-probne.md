## Входные тесты — по одному на лекцию

Каждый — около 5 минут. Ответьте кратко, затем проверьте.

:::task level=1 source=own title="В1 · Корректность алгоритмов"
1. Дайте определение **частичной корректности**.
2. Чем от неё отличается **полная корректность**?
3. Частично ли корректен алгоритм `sum = 0; i = 0; while(i < len) sum += a[i]; return sum` (нет `i++`)? Полностью ли?
::solution
1. Алгоритм частично корректен, если **если он остановится** (на корректных данных), **то** вернёт корректный результат.
2. Полная = частичная корректность **+ свойство остановки** (останавливается на любых корректных данных).
:::answer
3. **Частично корректен — да** (останавливается только при len = 0 и тогда возвращает верный 0). **Полностью — нет** (при len > 0 цикл бесконечен).
:::
:::

:::task level=1 source=own title="В2 · Вычислительная сложность"
1. Что такое **доминирующая операция**?
2. Дайте определение $f(n)=O(g(n))$.
3. Упорядочите по возрастанию порядка: $n\log n$, $\sqrt n$, $2^n$, $\log n$, $n^2$.
::solution
1. Операция (множество операций), число которой **пропорционально числу всех операций** алгоритма.
2. $f(n)=O(g(n)) \iff \exists_{c>0}\,\exists_{n_0}\,\forall_{n\ge n_0}\; f(n)\le c\cdot g(n)$.
:::answer
3. $\log n \prec \sqrt n \prec n\log n \prec n^2 \prec 2^n$.
:::
:::

:::task level=1 source=own title="В3 · Поиск"
1. Какому условию должны удовлетворять данные для двоичного поиска?
2. Укажите индексы, сравниваемые с ключом, и результат: S = 1, 3, 5, 7, 9, 11, 13; key = 11.
3. Укажите $W(len)$ последовательного и двоичного поиска.
::solution
1. Последовательность **отсортирована по неубыванию** (и лежит в памяти с произвольным доступом — RAM).
2. l=0, r=6 → m=3 (7 < 11) → l=4; m=5 (11) — найдено.
:::answer
2. Индексы **3, 5**, результат **5**. 3. Последовательный $W=len$, двоичный $W=\Theta(\log_2 len)$.
:::
:::

:::task level=1 source=own title="В4 · Сортировка 1"
1. Укажите массив после **2 проходов** insertion sort для 5, 2, 4, 1.
2. Чему равны $W$ и $A$ для selection sort?
3. Какова пространственная сложность `merge` (на массивах) и почему?
::solution
1. Проход 1: 2, 5, 4, 1. Проход 2: 2, 4, 5, 1.
2. $W=A=\frac{n(n-1)}{2}=\Theta(n^2)$ — число сравнений не зависит от данных.
:::answer
1. **2, 4, 5, 1**. 2. $W=A=\Theta(n^2)$. 3. $S(n)=\Theta(n)$ — выделяем массив `result` под слитые последовательности.
:::

:::task level=1 source=own title="В5 · Сортировка 2"
1. Когда алгоритм сортировки **устойчив**?
2. Выполните `partition` (опорный = первый) на 4, 7, 1, 6, 2: индекс, массив, число swap.
3. Какова нижняя граница сортировки сравнениями?
::solution
1. Когда сохраняет относительный порядок элементов с **равными** значениями.
2. swap(1, 4): 4, 2, 1, 6, 7; i останавливается на 6 (индекс 3), j спускается до i; a[3] = 6 > 4 → опорный на индекс 2.
:::answer
2. Индекс **2**, массив **1, 2, 4, 6, 7**, swap **2**. 3. $\Theta(n\log n)$ (так как $\log_2 n! = \Theta(n\log n)$).
:::

:::task level=1 source=own title="В6 · Рекурсия"
1. Сколько ходов требует hanoi(4)?
2. Решите $t(n)=t(n/2)+c$, $t(1)=0$.
3. Примените основную теорему к $T(n)=2T(n/2)+\Theta(n)$.
::solution
1. $\text{hanoi}(n)=2^n-1$.
2. $n=2^k$: $t(2^k)=t(2^{k-1})+c=\dots=kc=c\log n$.
3. $a=b=2$: $n^{\log_2 2}=n$, $f(n)=\Theta(n)$ — случай 2.
:::answer
1. **15**. 2. $\Theta(\log n)$. 3. $\Theta(n\log n)$ (mergeSort).
:::
:::

:::task level=1 source=own title="В7 · Списки и абстрактные структуры данных"
1. Что такое абстрактная структура данных?
2. Укажите интерфейс стека и его принцип.
3. Почему дек реализуют на **двусвязном** списке?
::solution
1. Структура, заданная **набором операций** (интерфейсом), без вникания в реализацию.
2. `push(e)`, `pop()`, `top()` — **LIFO**.
:::answer
3. Потому что `popBack` на односвязном списке требует прохода по всему списку ($O(n)$); на двусвязном все операции $O(1)$.
:::
:::

:::task level=1 source=own title="В9 · Словари, BST, хеширование"

2. Вставьте в пустое BST 8, 3, 12, 6, 15, 5 и укажите обход in-order.

::solution

2. Дерево: 8(3(_, 6(5, _)), 12(_, 15)).

:::task level=1 source=own title="В10 · Введение в графы"
1. Дайте две равносильные характеризации дерева с n вершинами.
2. Какова стоимость памяти матрицы смежности и списков смежности?
3. Когда орграф сильно связен?
::solution
1. Например: связен и имеет $n-1$ рёбер; ацикличен и имеет $n-1$ рёбер; любые две вершины соединены ровно одним элементарным путём.
2. Матрица $\Theta(n^2)$, списки $\Theta(n+m)$.
:::answer
3. Когда для **каждой упорядоченной пары** различных вершин есть ориентированный путь из первой во вторую.
:::

:::task level=1 source=own title="В11 · BFS и DFS"
Неориентированный граф: A–B, A–C, B–D, C–D, D–E (соседи по алфавиту).
1. Порядок BFS из A и расстояния `d`.
2. Порядок DFS (рекурсивного) из A и времена `d/f`.
3. Какую структуру данных использует BFS, а какую DFS?
::solution
1. A (0); B, C (1); D (2, через B); E (3).
2. A → B → D → C (соседи D: B, C, E) → возврат → E.
:::answer
1. **A, B, C, D, E**; d: A 0, B 1, C 1, D 2, E 3. 2. **A, B, D, C, E**; d/f: A 0/9, B 1/8, D 2/7, C 3/4, E 5/6. 3. BFS — **очередь**, DFS — **стек** (рекурсия).
:::
:::

:::task level=1 source=own title="В12 · Кратчайшие пути"
1. Запишите релаксацию ребра (u, v).
2. Когда нельзя применять алгоритм Дейкстры?
3. Укажите сложность: DAG, Дейкстра (двоичная куча), Беллман-Форд.
::solution
1. `if u.distance + w(u,v) < v.distance: v.distance = u.distance + w(u,v); v.parent = u`.
2. Когда в графе есть **отрицательные** веса рёбер.
:::answer
3. DAG $O(n+m)$; Дейкстра $O((n+m)\log n)$; Беллман-Форд $O(nm)$.
:::
:::

3. Краскал на графе A–B (1), B–C (2), A–C (2), C–D (3), B–D (3): рёбра в порядке принятия (равенство — по алфавиту).

## Пробный тест знаний

10 вопросов × 2 балла. Отвечайте полными предложениями: определение + обоснование.

:::task level=1 source=own title="K1 · Корректность"
Дайте определения полной и частичной корректности. Приведите пример алгоритма, у которого есть свойство остановки, но который не частично корректен.
::solution
Определения — как в [конспекте темы 2](topic:t02). Пример: `sum(array, len)`, возвращающий `sum + 1`, — всегда останавливается (цикл с `i++`), но результат неверен.
:::

:::task level=2 source=own title="K2 · Спецификация и псевдокод"
Напишите спецификацию и псевдокод функции `count(arr, len, key)`, возвращающей число вхождений `key` в массив. Укажите доминирующую операцию, размер данных и сложность.
::solution
- **предусловие:** arr — массив целых чисел, len — натуральное число (длина), key — целое число,
- **постусловие:** число индексов $0\le i<len$, для которых `arr[i] == key` (0 для пустого массива).
```pseudo
count(arr, len, key){
  c = 0
  i = 0
  while(i < len){
    if(arr[i] == key) c++
    i++
  }
  return c
}
```
:::answer
Доминирующая операция: сравнение `arr[i] == key`; размер: len; $W(len)=A(len)=len=\Theta(len)$, $S=O(1)$.
:::
:::

:::task level=2 source=own title="K3 · Анализ кода"
Укажите временную и пространственную сложность:
```pseudo
f(n){
  s = 0
  for(i = 0; i < n; i++){
    j = 1
    while(j < n){ s++; j = j * 2 }
  }
  return s
}
```
::solution
Доминирующая операция: `s++`; размер данных: $n$. Внутренний цикл: $j = 1, 2, 4, \dots < n$ — около $\lceil\log_2 n\rceil$ оборотов; внешний — $n$ раз.
:::answer
$W(n)=A(n)=\Theta(n\log n)$, $S(n)=O(1)$.
:::
:::

:::task level=2 source=own title="K4 · Инвариант"
Для алгоритма суммирования массива (`sum = 0; i = 0; while(i < len){ sum += a[i]; i++ }`) укажите инвариант и докажите полную корректность.
::solution
**Остановка:** $i$ растёт на 1, $len$ постоянна и конечна. **Инвариант:** $\text{sum}=\sum_{j=0}^{i-1} a[j] \wedge i\le len$. Перед циклом: $i=0$, пустая сумма $=0$ ✓. Шаг: после итерации $\text{sum}'=\sum_{j=0}^{i-1}a[j]+a[i]=\sum_{j=0}^{i}a[j]$, $i'=i+1$ ✓. Конец: $i=len$ ⇒ $\text{sum}=\sum_{j=0}^{len-1}a[j]$ ✓.
:::

:::task level=2 source=own title="K5 · Асимптотическая нотация"
Дайте определения $O$ и $\Theta$. Докажите по определению, что $3n+5=\Theta(n)$.
::solution
$3n+5\le 8n$ при $n\ge1$ ⇒ $O(n)$ ($c=8$, $n_0=1$); $n\le 3n+5$ при $n\ge 1$ ⇒ $n=O(3n+5)$ ($c=1$). Оба направления ⇒ $\Theta(n)$.
:::

:::task level=2 source=own title="K6 · Сравнение сортировок"
Сравните insertion sort, merge sort и quick sort: W, A, память, устойчивость. Когда insertion sort лучше всех?
::solution
| | W | A | память | устойчив |
|---|---|---|---|---|
| insertion | $\Theta(n^2)$ | $\Theta(n^2)$ | $O(1)$ | да |
| merge | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n)$ | да (зависит от `<`/`<=` в merge) |
| quick | $\Theta(n^2)$ | $\Theta(n\log n)$ | на месте | нет |

Insertion — для **почти отсортированных** данных (отсортированные: $n-1$ сравнений) и малых $n$.
:::

:::task level=2 source=own title="K7 · Стек и очередь"
Как реализовать очередь на массиве и на списке, чтобы все операции были $O(1)$? Почему обычного массива недостаточно?
::solution
Односвязный список с указателями на начало и конец (inject в конец, out из начала) или **циклический массив** (индексы начала и конца, арифметика mod $n$). В обычном массиве извлечение из начала требует сдвига элементов — $O(n)$.
:::

:::task level=2 source=own title="K8 · Хеш-таблицы"
Опишите требуемые свойства хеш-функции, методы разрешения коллизий и сложность. Почему хеш-таблица — плохая реализация упорядоченного словаря?
::solution
Быстрая (постоянное время) и равномерная; многократное хеширование или цепочки; операции $O(\alpha)$, $\alpha=n/m$. Минимум, максимум, последователь, предшественник требуют просмотра всей таблицы — линейно (хеш-функция разрушает порядок ключей).
:::

:::task level=2 source=own title="K9 · BST и AVL"
Сравните W и A операций на BST и AVL. Что такое bf и какому условию удовлетворяет AVL? Почему это даёт $O(\log n)$?
::solution
BST: $A=O(\log n)$, $W=O(n)$ (одна ветвь). AVL: $bf(x)=h(L)-h(R)\in\{-1,0,1\}$ для каждого узла ⇒ высота $O(\log n)$ ⇒ все операции $W=O(\log n)$ (исправление поворотами за $O(1)$).
:::

:::task level=2 source=own title="K10 · Выбор алгоритма на графе"
Какой алгоритм кратчайших путей выберете и с какой сложностью: a) ориентированный ацикличный граф с отрицательными весами, b) дорожная сеть (веса ≥ 0), c) граф с отрицательными весами и циклами? Для чего нужен Краскал и какова его сложность?
::solution
:::answer
a) **DAG** (топологическая сортировка + релаксация) $O(n+m)$ — отрицательные веса не мешают. b) **Дейкстра** $O((n+m)\log n)$. c) **Беллман-Форд** $O(nm)$ (+ поиск отрицательных циклов). Краскал — минимальное остовное дерево, $O(m\log m)$.
:::
:::
