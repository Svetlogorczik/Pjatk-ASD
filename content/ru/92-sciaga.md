## Нотации и формулы

- f = O(g) ⇔ ∃ c > 0, n₀: f(n) ≤ c·g(n) при n > n₀; Ω — наоборот; Θ = O и Ω.
- 1 ≺ log n ≺ √n ≺ n ≺ n log n ≺ n² ≺ n³ ≺ 2ⁿ ≺ n!
- log(xy) = log x + log y; log xᵏ = k log x; log_a x = log_b x / log_b a; цифр: ⌊log₁₀ x⌋ + 1.
- 1 + 2 + … + n = n(n+1)/2; 1 + 2 + 4 + … + 2ᵏ = 2ᵏ⁺¹ − 1; log n! = Θ(n log n).
- **Основная теорема** T(n) = aT(n/b) + f(n): сравнить f с n^(log_b a) → медленнее: Θ(n^(log_b a)); так же: Θ(n^(log_b a) log n); быстрее: Θ(f).
- Фибоначчи: Fₙ ≈ φⁿ/√5, φ ≈ 1,618 (Евклид, AVL).

## Поиск и выбор

| Алгоритм | Сложность |
|---|---|
| последовательный (сторож) | W = n + 1, A = (n+1)/2 |
| бинарный | ⌈log₂ n⌉ + 1 |
| max | n − 1 (оптимально) |
| min и max | ⌈3n/2⌉ − 2 (оптимально) |
| второй по величине | n + ⌈log₂ n⌉ − 2 |
| k-й — Хоар | W = ½n² + O(n), A = O(n) |
| Евклид (mod) | O(log n) |

## Сортировки

| Алгоритм | Худший | Средний | Память | Устойчив |
|---|---|---|---|---|
| SelectionSort | n²/2 | n²/2 | O(1) | нет |
| InsertionSort | n²/2 | n²/4 | O(1) | да |
| MergeSort | n log n | n log n | O(n) | да |
| QuickSort | n²/2 | 1,4 n log n | O(log n) | нет |
| HeapSort | 2n log n | ~2n log n | O(1) | нет |
| CountingSort | O(n + m) | O(n + m) | O(n + m) | да |
| RadixSort | O(d(n + k)) | O(d(n + k)) | O(n + k) | да |
| **нижняя оценка (сравнения)** | ⌈log₂ n!⌉ = Ω(n log n) | | | |

## Структуры данных

| Структура | Операции |
|---|---|
| стек (массив/список) | push, pop, top — O(1) |
| очередь (список/циклический массив) | inject, front, pop — O(1) |
| двусвязный список | вставка/удаление у узла O(1); доступ к позиции p — O(p) |
| отсортированный массив | search O(log n); insert, delete O(n) |
| BST | O(h): в среднем O(log n), в худшем O(n) |
| AVL | search, insert, delete — O(log n); h < 1,44 log n |
| хеш-таблица | в среднем O(1), в худшем O(n) |
| куча | insert O(log n), deletemax 2⌊log n⌋, construct O(n) |
| левосторонняя куча | слияние, insert, deletemax — O(log n) |
| Find-Union (деревья + сжатие) | почти O(1) на операцию |

## Важные числа

- Ханой: 2ⁿ − 1 ходов. Перестановки: n!.
- AVL: максимум 2ʰ⁺¹ − 1 узлов, минимум N(h) = N(h−1) + N(h−2) + 1 (1, 2, 4, 7, 12, 20, 33).
- Куча: сыновья 2k, 2k+1; отец ⌊k/2⌋; h = ⌊log n⌋; листья: позиции > ⌊n/2⌋.
- Неориентированный граф: m ≤ n(n−1)/2.
