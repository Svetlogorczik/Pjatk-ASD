## Прежде чем считать сложность

:::formula Два шага + меры
1. **доминирующая операция**, 2. **размер данных**.
$$W(n)=\sup\{t(d):d\in D_n\} \qquad A(n)=\sum_k p_{nk}\,k=E(X_n) \qquad S(n)\text{ — память}$$
:::

| | значит | определение |
|---|---|---|
| $O$ | ≤ | $\exists_{c>0}\exists_{n_0}\forall_{n\ge n_0}\,f\le c\,g$ |
| $\Omega$ | ≥ | $\exists_{c>0}\exists_{n_0}\forall_{n\ge n_0}\,f\ge c\,g$ |
| $\Theta$ | = | $O$ в обе стороны |
| $o$ / $\omega$ | < / > | $\forall_{c>0}$ вместо $\exists_{c>0}$ |

$$1 \prec \log n \prec \sqrt n \prec n \prec n\log n \prec n^2 \prec n^3 \prec 2^n \prec n!$$

## Поиск

| Алгоритм | Сложность |
|---|---|
| последовательный | $W=len$, $A=\frac{len+1}{2}$ |
| прыжки через $k$ | $\frac1k\Theta(len)$, лучше всего $k=\sqrt{len}$ |
| двоичный (отсортировано, RAM) | $\Theta(\log_2 len)$, $S=O(1)$ |
| 2-й наименьший — турнир | $len-1+\Theta(\log len)$ |
| partition | $W=n+O(1)$, $S=O(1)$ |
| Хоар (k-й) | $A=\Theta(n)$, $W=\Theta(n^2)$ |

## Сортировка (операция: сравнение)

| Алгоритм | W | A | память | устойчив |
|---|---|---|---|---|
| Selection | $\frac{n(n-1)}{2}$ | $=W$ | $O(1)$ | нет |
| Insertion | $\frac{n(n-1)}{2}$ | $\frac14n^2+\Theta(n)$ | $O(1)$ | да |
| MergeSort | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n)$ | да* |
| QuickSort | $\Theta(n^2)$ | $\Theta(n\log n)$ (≈1,44) | на месте | нет |
| HeapSort | $\Theta(n\log n)$ | $\Theta(n\log n)$ | — | нет |
| CountSort | $\Theta(n+m)$ | $\Theta(n+m)$ | $\Theta(n+m)$ | да |
| RadixSort | $\Theta(d(n+10))$ | | | да |

\* при `<=` в merge; версия со слайда с `<` при равенстве берёт из правой последовательности. **Нижняя граница сравнениями:** $\log_2 n!=\Theta(n\log n)$.

## Рекурсия

| Уравнение | Решение |
|---|---|
| $t(n)=t(n/2)+c$ | $\Theta(\log n)$ |
| $t(n)=2t(n/2)+c$ | $\Theta(n)$ |
| $t(n)=2t(n/2)+cn$ | $\Theta(n\log n)$ |
| hanoi | $2^n-1$ |

**Основная теорема** $T(n)=aT(n/b)+f(n)$ — сравните $f$ с $n^{\log_b a}$: меньше → $\Theta(n^{\log_b a})$, равно → $\cdot\log n$, больше → $\Theta(f)$.

## Структуры данных

| Структура | Операции |
|---|---|
| стек / очередь / дек | $O(1)$ (односвязный список / циклический массив / двусвязный список) |
| связный список | splice, вставка/удаление у узла $O(1)$; доступ $O(n)$ |
| словарь — наивные массивы | неотсорт.: search $O(n)$, insert $O(1)$; отсорт.: search $O(\log n)$, insert $O(n)$ |
| хеш-таблица | $O(\alpha)$, $\alpha=n/m$ |
| BST | $A=O(\log n)$, $W=O(n)$ |
| AVL | всё $W=O(\log n)$; $bf\in\{-1,0,1\}$ |
| двоичная куча (min) | insert, delMin $O(\log n)$; findMin $O(1)$; construct $O(n)$; merge $O(n)$ |

**Куча в массиве с 1:** родитель $\lfloor i/2
floor$, сыновья $2i$, $2i+1$.

## Соглашения теста (здесь легко потерять баллы)

:::warn Запомните
- binSearch: `m = (l+r)/2` **вниз**; MergeSort: `m = len/2` — **левая короче**,
- partition: считается **последний** swap; CountSort: фаза 3 **с конца**,
- куча с индекса **1**; `construct` ≠ n × `insert`,
- BST: равный ключ **вправо**; DFS: `time` с **0**,
- соседи и равенства (Краскал, Прим) — **по алфавиту**.
:::
